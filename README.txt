# モンスト反射シミュレーター（試作版）

## できること
- スクリーンショット読み込み
- 発射位置・角度の指定
- 画面端・矩形ブロックでの反射
- 敵キャラへの接触位置の表示（敵は軌道を反射させず、接触イベントとして表示）
- 反射回数の設定
- 手動でのブロック・敵配置
- 暗い領域を使った簡易自動検出（実験機能）

## iPhoneでホーム画面に追加する方法
このフォルダ一式をHTTPS対応の静的ホスティング（例：GitHub Pages）に公開してください。iOSではローカルHTMLファイルを開くだけでは、通常のホーム画面追加型Webアプリとしてインストールできません。

公開後、iPhoneのSafariで公開URLを開き、
1. 共有ボタンを押す
2. 「ホーム画面に追加」を選ぶ
3. 「Webアプリとして開く」が表示される場合は有効にして追加

## 注意
これは軌道幾何の試作です。実際のモンストのキャラサイズ、壁判定、敵との衝突半径、速度変化、加速床・減速床・ワープ等のギミック、キャラ固有性能を完全再現しません。自動検出は画像の暗い領域をブロック候補として拾う簡易方式なので、必ず目視で修正してください。

## ファイル
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面追加用設定
- sw.js: オフラインキャッシュ
- icon-192.png / icon-512.png: アイコン
